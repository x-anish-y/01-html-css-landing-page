# NovaPulse — HTML & CSS Landing Page

A modern, fully responsive landing page for **NovaPulse**, a fictional SaaS analytics platform. Built with pure HTML and CSS — no frameworks or build tools required.

![Screenshot Placeholder](https://via.placeholder.com/1200x630?text=NovaPulse+Landing+Page)

## ✨ Features

- **Semantic HTML5** — Properly structured with `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, and ARIA attributes
- **CSS Custom Properties** — Consistent design tokens for colors, spacing, typography, and shadows
- **Flexbox & CSS Grid** — Modern layout techniques for every section
- **Fully Responsive** — Optimized for mobile (≤640px), tablet (≤900px), and desktop breakpoints
- **Accessible** — Keyboard navigation, visible `:focus-visible` states, `aria-label` attributes, and semantic landmarks
- **Smooth Interactions** — Hover effects, transitions, and a floating hero animation via CSS `@keyframes`
- **Mobile Hamburger Menu** — Toggle navigation with animated hamburger ↔ X icon (minimal vanilla JS)

## 📐 Page Sections

| Section       | Description                                                     |
|---------------|-----------------------------------------------------------------|
| **Header**    | Sticky navbar with logo, nav links, CTA button, hamburger menu  |
| **Hero**      | Headline with gradient text, subtext, 2 CTAs, SVG illustration  |
| **Features**  | 3-column grid of feature cards with icons                       |
| **How It Works** | 3-step process with numbered badges                          |
| **CTA Banner** | Full-width gradient call-to-action section                     |
| **Footer**    | Link columns, social icons, copyright, legal links              |

## 🛠 Tech Stack

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid, Media Queries)
- Vanilla JavaScript (mobile menu toggle only)

## 🚀 Setup & Run

No build tools needed. Simply open `index.html` in your browser:

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/01-html-css-landing-page.git
cd 01-html-css-landing-page

# Open in browser (macOS)
open index.html

# Or use a local server
npx serve .
```
